# Ragnar MSX

Layout melhorado para Media Station X baseado no design proposto.

## Como usar

1. No Media Station X, v\u00e1 em Settings \u2192 Start Parameter \u2192 Setup
2. Coloque o endere\u00e7o: `https://raw.githubusercontent.com/fscheeren92-a11y/Ragnar-MSX/main/msx/start.json`
   (ou use o GitHub Pages / seu servidor se preferir)
3. Reinicie o app

## Estrutura

- `msx/start.json` - Ponto de entrada
- `msx/menu.json` - Menu lateral com \u00edcones
- `msx/home.json` - Destaque da s\u00e9rie
- `msx/movies.json` - Biblioteca de filmes

Substitua as imagens placeholder pelas reais.
